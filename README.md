# UDCF Digital Twin v4.0 PRO
**The Yeboah Institute Research Ghana**

## Overview
The **Unified Dimensionless Cutting Framework (UDCF)** Digital Twin is a high-fidelity physics simulation tool designed to analyze and predict target material severance. It utilizes kinematic, geometric, and systemic vectors to calculate the **Separation Index (\(\eta\))**, providing researchers with a precise digital environment to test cutting efficiency.

## Key Features
- **Live Physics Render Engine:** Real-time animation of material separation.
- **SI Vector Analysis:** Normalized visualization of Kinematic, Geometric, and Systemic efficiency.
- **Dynamic Energy Mapping:** Real-time Chart.js integration comparing Available Energy vs. Required Work.
- **LaTeX Integration:** Professional mathematical rendering using MathJax.
- **Research Data Export:** One-click CSV export for empirical data logging.

## The Mathematical Framework
The simulation is governed by three primary equations:
1. **Impedance Factor (\(\Phi\)):** \(\Phi = \exp[\tan(\theta_w/2) + \mu]\)
2. **Separation Index (\(\eta\)):** \(\eta = k_Y \left[ \frac{mv^2}{2d\tau_{ult}A\Phi} \right]\)
3. **Critical Velocity (\(v_{crit}\)):** \(v_{crit} = \sqrt{ \frac{2d\tau_{ult}A\Phi}{m \cdot k_Y} }\)

## Installation
No installation is required. Simply download `index.html` and open it in any modern web browser.
